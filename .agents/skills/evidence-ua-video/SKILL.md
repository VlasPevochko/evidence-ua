# Evidence UA Video

## Overview

Create visually strong Ukrainian evidence-based health videos without making the science stronger, cleaner, or more certain than the underlying evidence.

**Core principle:** visual impact may be amplified; scientific certainty may not.

## Required references

For any factual health/medical claim, **REQUIRED:** read `references/evidence-rules.md`.

For any video, scene plan, or Remotion composition, **REQUIRED:** read `references/video-contract.md`.

If implementing in Remotion, **REQUIRED SUB-SKILL:** use `remotion-best-practices` and the relevant Remotion creation/markup/captions skills.

## Workflow

1. **Define the claim.** Convert the topic into 1–3 answerable questions.
2. **Verify evidence before scripting.** Prefer current systematic reviews/meta-analyses, high-quality RCTs, and authoritative guidelines; use primary studies where needed.
3. **Build an evidence brief.** Record population, intervention/exposure, comparator, outcomes, dose, duration, effect size, uncertainty, limitations, and source.
4. **Choose one communication angle.** Hook must be accurate even when isolated from the rest of the video.
5. **Write the Ukrainian script.** Separate established findings, plausible mechanisms, uncertainty, and practical interpretation.
6. **Create the scene plan.** One primary idea per scene. Match every quantitative visual to a verified number.
7. **Select visual runtime.**
   - Remotion: precise typography, charts, diagrams, captions, reusable branded components.
   - Generated/stock video: biological atmosphere, context, B-roll.
   - Hybrid: default for Evidence UA explainers when both clarity and visual richness matter.
8. **Review before render.** Check every spoken/on-screen claim against the evidence brief; verify units, denominators, population, timeframe, and citations.
9. **Produce preview first.** When using Remotion, prefer an interactive preview; render/export only when explicitly requested.

## Output order

Return:
1. `Evidence brief`
2. `Hook + script`
3. `Scene plan`
4. `Visual/data plan`
5. `Sources`
6. `Uncertainty / limitations`
7. `Production notes`

## Non-negotiables

- Never invent a PMID, DOI, effect size, confidence interval, sample size, dose, or citation.
- Never convert association into causation.
- Never generalize animal/in-vitro evidence to humans without an explicit limitation.
- Never present a mechanism as a demonstrated clinical benefit.
- Never use “proven”, “guaranteed”, “safe”, or “effective” unless the evidence actually supports that wording in the stated population and context.
- If evidence is insufficient or conflicting, make that the conclusion rather than filling the gap.

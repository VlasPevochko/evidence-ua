# Уніфікація досьє добавок — 11 жовтня 2026

Поточний креатин збережено без зміни Claims, EVR і confidence. Для дев’яти інших добавок додано спільний структурований блок із поточним висновком, практичними орієнтирами, обмеженнями, джерелами, розгорнутим поясненням і статусом перевірки. Наявні сторінки, ілюстрації, навігація та protein-meta.html збережено.

Це перенесення наявного матеріалу, не завершена наукова переоцінка. Жодних нових результатів, чисел, DOI, PMID або confidence не створено. Неперевірені посилання не перетворено на фіктивні Evidence Records. Поля claimIds/evidenceRecordIds залишено порожніми до перевірки конкретних outcomes. Позначка «не оцінено» не означає LOW або INSUFFICIENT. Науковий перегляд не датовано днем технічного перенесення.

Усі дев’ять мають статус «Попередній огляд · рівні впевненості не оцінено». Для вітаміну D явно вказано одне РКД; магнію — довідник NIH; колагену — належність старих оцінок авторам огляду, не Evidence UA.

До повних досьє рівня креатину залишається: визначити конкретні Claims, перевірити повні тексти, вилучити PICO/ефекти/ДІ, створити outcome-specific EVR, виконати GRADE-informed оцінювання й отримати наукове погодження. Це не приховано в UI. Самі структуровані сторінки готові для всіх десяти, але дев’ять не слід називати завершеними науковими модулями.

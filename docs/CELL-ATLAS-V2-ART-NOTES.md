# Cell Atlas v2 illustration

Created with the built-in imagegen tool for the user's requested Cell Lab illustration refresh. The generated raster is saved as `dist/cell-atlas-v2.png` (1448 × 1086). Its original generated output is retained outside the project. Interactive contours and hover motion are separate presentation geometry in `src/cell-lab/illustration.mjs` and `dist/cell-lab.css`.

The plate is artistic educational anatomy, not a micrograph, measured reconstruction or live physiological simulation. Lysosome/peroxisome identities are assigned illustrative labels; colors do not establish vesicle identity. ER and cytoskeleton highlights show representative visible regions. Existing 11 entity IDs, text, source links, descriptive records and unassessed confidence remain unchanged. The old small SVG drawing is replaced only in the presentation controller.

Each organelle has a separate keyboard and pointer target. Nucleolus targets take priority within the nucleus; the membrane target covers only its boundary. Hover/focus previews leave selection, scientific explanation and URL untouched; activation chooses the structure. Hover motion is gentle translation/scale, with static highlights under reduced-motion preference.

Primary visual references used for review: [OpenStax organelles](https://openstax.org/books/anatomy-and-physiology-2e/pages/3-2-the-cytoplasm-and-cellular-organelles), [nucleus](https://openstax.org/books/anatomy-and-physiology-2e/pages/3-3-the-nucleus-and-dna-replication), [membrane](https://openstax.org/books/anatomy-and-physiology-2e/pages/3-1-the-cell-membrane). SVG clipping follows [CSS Masking](https://drafts.csswg.org/css-masking-1/#ClipPathElement); boundary/fiber fragments use stroked masks so their interior does not incorrectly brighten.

Create a polished high-detail 3D medical illustration with dimensional membranes, delicate internal textures, crisp organelles and sophisticated studio illumination on solid very dark graphite (#10151b) background. Wide 4:3 landscape canvas, cell occupies 82% width and 80% height, shallow three-quarter / almost top-down perspective, broad open front face so structures can be clearly identified and clicked. No text, no arrows, no labels, no numbers, no highlights; we add those interactively later. Keep controlled colors distinct but scientifically schematic, realistic material shading, no cute/cartoon style, no toys, no flat discs. All membrane-bound structures inside cell, nucleolus inside nucleus, no plant cell wall, no chloroplasts, no large central vacuole, no DNA helix floating outside nucleus. Aim for a credible university-level anatomy-atlas plate, highly detailed but visually clean and calm, not an overstuffed sci-fi scene.

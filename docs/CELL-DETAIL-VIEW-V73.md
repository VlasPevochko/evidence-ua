# Cell interior viewer

User intent: clicking any structure opens its internal detail inside the existing atlas, with approximate fourfold illustrative enlargement and no separate page. Hover stays a preview.

The existing Cell claims, descriptive records and source metadata remain unchanged. A presentation module associates the 11 existing entities with 11 original generated illustrations and short component labels. The close-ups are schematic art; molecular shapes, arrangement, number and scale are illustrative. Zoom is a viewer scale, not a microscope measurement. The nucleolus/ribosome lack membranes; the cytoskeleton is a filament network.

The viewer starts at 4×, offers 2×/4×/6×/8× and fit, and closes by button or Escape. Selection, level, tab and existing URL parameters stay in the same page. Closing returns focus to the selected atlas control. Source chapters are linked in every close-up.

Reference for labels: OpenStax Anatomy and Physiology 2e, chapters 3.1 (membrane), 3.2 (cytoplasm and organelles) and 3.3 (nucleus). Only structural labels were added; no intervention effects or evidence ratings. Artwork is original built-in imagegen output. Exact prompts and inspection notes are in cell-detail-art-a.md, cell-detail-art-b.md and cell-detail-art-c.md.

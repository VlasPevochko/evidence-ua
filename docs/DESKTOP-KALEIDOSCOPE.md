# Калейдоскоп головної — 18 жовтня 2026

Погоджено власником: зберегти хвилю й палітру; додати калейдоскопічне підсвічування наявних граней праворуч лише для комп’ютера. На телефоні зберегти хвилю без додаткового ефекту.

Прокручування сторінки плавно змінює шестипроменевий візерунок із вкладених кілець. Ефект працює від 1100 px за наявності hover і точного основного вказівника. Події wheel/touch не перехоплюються. Підсвічування розміщується праворуч від фактичного тексту заголовка та опису; за браку місця вимикається. Це декоративна геометрія, не наукова модель організму.

Reduced motion вимикає додатковий ефект. Прихована вкладка, pagehide і вихід hero за екран зупиняють анімацію. Попередня хвиля, палітра, текст, кнопки та наукові дані збережені. Версію JS у HTML піднято для оновлення кешу.

Змінені файли:

- `dist/home-geo-hero.js` — ефект та керування життєвим циклом.
- `dist/index.html` — тільки `home-geo-hero.js?v=2`.
- `tests/hero-kaleidoscope.test.mjs` — виконання реального renderer у контрольованому canvas/DOM-середовищі.
- `docs/DESKTOP-KALEIDOSCOPE.md` — цей контракт і межі перевірки.

Перевірки: новий тест спочатку падав через відсутню реакцію на scroll, після реалізації проходить. Перевірено desktop scroll, збереження touch-хвилі, збільшений текст, reduced motion, приховування вкладки та вихід за екран. Чинний home-geo-hero тест, JS syntax, content validation, retained build і smoke самого сайту проходять.

Повний локальний запуск на Node 24.19.0: 45/46 тестових файлів пройшли. `smoke-check.test.mjs:142` падає на негативному прикладі `export const = ;`; той самий збій відтворено на незмінених файлах із вихідного main `272cf46`. Це не збій нового renderer. Не змінювати smoke-перевірку в межах цієї правки.

Візуальний Browser QA нової анімації не виконано: у поточному managed-середовищі відсутній підтримуваний control-browser для локального preview. Автоматичні canvas-тести не доводять красу композиції чи плавність на пристрої. Перед злиттям потрібні CI та візуальний перегляд.

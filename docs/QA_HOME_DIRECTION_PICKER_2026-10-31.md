# Вибір напрямів після натискання — 31.10.2026

Шість нумерованих карток лінзи перенесено в закритий native dialog. На сторінці залишається анімоване зображення з кнопкою «Обрати напрям». Натискання відкриває панель із наявними власними ілюстраціями, назвами, статусами та адресами всіх шести напрямів. Хрестик, Escape і натискання на фон закривають її; фокус повертається до кнопки. Прокручування саме по собі не відкриває картки.

Перший екран, розділення лінзи, «З чого почати», навчальні маршрути, відгук, Атлас і бібліотека збережені. Наукові тексти не змінено; перевірка збереження одинадцяти наукових HTML-піддерев пройшла. Посилання «Добавки» як раніше розкриває бібліотеку. Без JS або dialog API кнопка веде на directions.html. Старі #cards відкривають панель за наявності підтримки.

## Перевірки

- Node 24.22.1: повна збірка, валідація змісту й smoke check пройшли.
- `node scripts/test-site.mjs`: **100/100** ізольованих наборів пройшли. Перший прогін виявив лише старий UI-контракт прямого розташування карток; його змінено відповідно до доручення, без зміни наукового еталона.
- 27 цільових тестів пройшли після остаточних CSS-правок. Для нового контролера зафіксовано RED → GREEN: шість перевірок спочатку падали через відсутній модуль, потім пройшли.
- Smoke: 21 HTML-сторінка, 99 JS-перевірок синтаксису, 183 локальні цілі та 293 HTML-якорі.
- Реальний Chromium через CUA: комп’ютер 1363×936; вкладене вікно 390×844; 360×667 з фактично вибраним великим текстом (zoom 1.12). Це перевірка браузерних макетів, не фізичного телефона чи Safari.
- До натискання картки мають нуль відмальованих прямокутників. При 1363 px висота головної скоротилася з 2435 до 2084 px. На ПК панель 900 px, усі шість карток 417×144 px, горизонтального переповнення немає.
- На 360×667 / zoom 1.12 спочатку відтворено обрізання: верх панелі −57.6 px. Заміна dvh на відсоток висоти fixed containing block дала верх 22.4 px і низ 667 px. Після прокрутки останній напрям розташований у межах 451–644 px, хрестик — 45.8–95.1 px; переповнення по горизонталі нульове.
- Перевірено native Escape, повернення фокуса, клавіатурний доступ до останнього напряму і реальний перехід до #supplement-library із закриттям панелі та розкриттям бібліотеки.
- Browser QA у CI оновлено для click-to-open, native fallback, клавіатури, touch, reduced motion, коротких екранів, великого тексту, меж панелі й останньої картки. Його результат слід читати в перевірках PR; локальний Playwright не запускався.
- Незалежний read-only огляд: критичних чи суттєвих дефектів не підтверджено; 27 цільових тестів незалежно пройшли.

## Дрібні зауваження огляду, відкладено

1. Старий `background:none!important` пригнічує задуманий додатковий відтінок тла карток/hover. Поточний відмальований вигляд збережено у скриншоті; читабельність, фокус і переходи працюють.
2. Перевірка idle у зміненому браузерному сценарії порівнює кінцевий style й не рахує повторні однакові записи або RAF. Наявні 19 тестів контролера руху збережено; повернення детального браузерного лічильника лишається окремим поліпшенням перевірок.

Зауваження про межі панелі та останню картку опрацьовано: браузерні вимірювання й відповідні CI-перевірки додано. Злиття й публікацію не виконано: для нового PR діє правило власника в CLAUDE.md.

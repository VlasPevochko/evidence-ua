# Структуровані вилучення — 11 жовтня 2026

Додано ізольовану локальну чернетку: 4 джерела, 4 наукові питання, 5 результатів. Питання не позначено як схвалені Claims; усі результати pending, confidence=null. Оцінка за GRADE-informed підходом не виконана. Public data та сайт не змінено.

Перенесено вже зафіксовані в попередніх звітах результати: два дозові підрозділи аеробних тестів кофеїну, переломи для вітаміну D окремо, зміну частоти ідіопатичних судом для магнію, загальну працездатність для цитруліну малату. У кожного є посилання, locator, контекст та обмеження. Нових чисел або висновків не додано.

Старі чернетки збережено без змін. Невідомі outcome-specific вибірки кофеїну залишено null; кількість оцінок цитруліну відокремлено від кількості РКД. Вилучення не є завершеним аудитом повного тексту або незалежною оцінкою ризику упередженості. Розбіжність бета-аланіну та недоступні результати не перенесено як перевірені.

Перед записом збережено резервну копію. Перевірено посилання між сутностями, межі ДІ, невідомі вибірки та заборону публікації; негативні тести перевіряють пошкоджені посилання й інтервали. Existing scientific-draft та update-search тести також запущено. Це структурна перевірка, не наукове схвалення.

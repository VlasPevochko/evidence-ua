# v50 — пакет решти досьє

Одним пакетом додано блоки протеїну, омега-3, магнію, колагену, бета-аланіну й електролітів. Разом із попередніми оновленнями всі дев’ять досьє мають джерело-специфічний блок, контекст та обмеження. Це не дев’ять завершених наукових модулів і не повністю актуалізовані систематичні огляди.

Перевірені раніше числа перенесено для протеїну, омега-3, магнію та колагену. Для бета-аланіну й електролітів кількісного результату не додано: показано конкретне питання та причину незавершеності перевірки. Нові рівні впевненості, дозування або Claims не присвоєно. Старі висновки, джерела й матеріали збережено. Нові блоки залишаються під позначкою попереднього огляду.

Резервну копію збережено до змін. Змінені файли:

- src/evidence/supplements/published-study-notes.mjs — шість нових блоків.
- tests/published-study-notes.test.mjs — охоплення всіх дев’яти тем; відсутність неперевірених чисел.
- dist/index.html — генерація блоків.
- docs/V50-ALL-DOSSIERS-REPORT.md — цей звіт.

Перевірки: генерація, повторна генерація без змін, dossier та study-note тести; ізоляція дослідницьких чернеток. Мобільну візуальну перевірку не виконано через недоступність браузерного інструмента. Блоки використовують існуючий адаптивний компонент; routing, головну та інтерактиви не перероблено.

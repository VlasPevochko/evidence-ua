## Науковий зміст

Використано існуючі чотири кроки, пояснення, джерела й SVG storyboard. Нових наукових тверджень, концентрацій, швидкостей, числових ефектів або оцінок впевненості не додано. Статус незавершеного наукового перегляду збережено. На цьому етапі змінено спосіб керування та розміщення, а не наукову модель.

## Перевірки

- Синтаксис `dist/muscle-lab.js` — пройдено.
- 5/5 тестових файлів: Muscle Lab, knowledge registry, evidence module, досьє, published notes — пройдено.
- Вкладеність HTML сторінки й згенерованих тем, унікальність IDs та цілі aria-controls — пройдено.
- Реальні handlers перевірено через DOM adapter; це не браузерна візуальна перевірка.
- Вигляд у браузері на 360/390 px не перевірено: відповідна browser QA capability недоступна. Responsive CSS перевірено статично.

Головна сторінка, добавки, зовнішні джерела, загальна навігація та інші Labs не змінені.

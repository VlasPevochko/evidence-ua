# Evidence UA: карта та спільна навігація платформи

## Результат

Створено єдиний каталог доступних напрямків, матеріалів і маршрутів навчання. Каталог використовується сторінкою `directions.html` та спільним компонентом навігації. Це завершений етап інформаційної архітектури; він не означає завершення всіх наукових модулів із Project Bible.

- Доступні напрямки: м’язи / тренування, клітини / органели, харчування, добавки, візуальний ескіз руху. Рівень готовності кожного показано словами.
- Три маршрути: будова й рух; клітина та енергія; харчування й читання доказів.
- Матеріали мають прямі посилання на сторінки, розділи та вибрані структури. Переходи між етапами маршруту передають позицію в URL.
- Пошук охоплює назви напрямків, матеріалів і канонічних сутностей. Наприклад, «саркомер» знаходить Muscle Lab без дублювання назви у пошуковому словнику.
- Заплановані Metabolism Lab, порівняння, матеріали для викладачів та Еві відділено від доступного контенту. Вони не мають фальшивих активних посилань.
- Наявний перший екран головної збережено: додано один пункт меню «Напрями», без додаткової панелі на першому екрані. На окремих сторінках і в досьє є компактна спільна навігація.
- У вбудованому iframe травлення нова панель не додається.

## Архітектурний контракт

`src/platform/catalog.mjs` — джерело навігаційних даних; це не сховище нових наукових Claims. Валідація перевіряє унікальні IDs, локальні посилання, існування сутностей і маршрутів. `scripts/build-platform.mjs` перевіряє файли сторінок та генерує deploy-каталог; він підключений до build-knowledge.

Спільний каталог дозволяє додавати напрям через дані та загальні компоненти, без спеціального нового renderer. Послідовність навчання не позначає причинний вплив. Новий рейтинг доказів, персональний профіль, tracking, server backend, CMS, автоматичне оновлення висновків або Еві не реалізовувалися.

## Перевірки й обмеження

- `node scripts/build-knowledge.mjs` — пройдено.
- Синтаксис нових контролерів та контролерів Muscle/Cell Lab — пройдено.
- `node --test tests/*.test.mjs` — 12/12 test files пройдено. Після доповнення перевірок shared shell повторно пройдено `tests/platform.test.mjs`.
- Перевірено файли доступних посилань та якорі з урахуванням розділів, які створюються JavaScript.
- Перевірено переходи між матеріалами, невідомі параметри, відкриття рибосоми / м’язового волокна, reset пошуку, фільтр атласів, відсутність активних посилань для запланованого контенту.
- HTML карти та згенерованих карток, маршрутів і навігації: вкладеність і IDs — пройдено.
- Браузерний layout, візуальний вигляд 360/390 px та повне проходження клавіатурою не перевірено: відповідна browser QA capability недоступна. Тести використовують статичні перевірки й DOM adapters; це не візуальна сертифікація.

## Науковий зміст

Жодні Claims, результати EVRs, наукові джерела, рівні впевненості чи наукові дати перегляду не змінені. Наукові формулювання в досьє та Labs залишилися попередніми там, де вони були попередніми. Наявність матеріалу в каталозі не означає завершений науковий перегляд.

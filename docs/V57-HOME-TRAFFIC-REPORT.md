# Evidence UA · головна перед першим трафіком · v57

Мета — допомогти новому відвідувачеві зрозуміти сайт і знайти перший матеріал. Перший екран, фотографії, заголовок, кольорова гама та науковий зміст збережені. Змінено лише ціль кнопки «Дослідити» й блоки після hero.

## Реалізовано

- «Дослідити» відкриває `#start-here`, а не одразу бібліотеку добавок.
- Короткий вступ пояснює формат платформи: інтерактиви, досьє, джерела та межі пояснень.
- Три стартові переходи: Nutrition Lab, докази креатину й будова м’яза в Muscle Lab.
- Головні картки беруть доступні напрямки зі спільного каталогу: м’язи/тренування, клітини/органели, харчування, добавки та візуальний ескіз руху. Статус кожного показано на картці; доступність не означає завершений науковий перегляд.
- Ще неготові напрямки більше не займають основну сітку як начебто доступні матеріали. Початкові описи майбутніх тем у вихідному коді не видалено; планування майбутніх Labs у каталозі також збережено.
- Прямі переходи до карти платформи та наявного посібника «Як читати докази».
- Згорнутий блок із трьома запитаннями для першого враження: що зрозуміло, де виникла перешкода, що змінити першим.

## Відгуки та приватність

Форма **не надсилає відповіді й не зберігає їх на сервері**. Вона збирає текст для ручного копіювання та передачі людині, яка поділилася сайтом. Це явно пояснено до заповнення та після створення тексту.

Не додано лічильник відвідувань, рекламні пікселі, автоматичні метрики кліків, cookies, localStorage чи автоматичний запис відповідей. Кількісна аналітика трафіку цим етапом **не підключена**. Системні журнали хостингу не прирівнюються до доступної нам аналітики поведінки.

Користувач сам указує пристрій; user agent не збирається. Параметри URL і fragment не копіюються в текст. Є попередження не вписувати персональні або медичні дані. Якщо Clipboard API недоступний/заблокований, текст виділяється для ручного копіювання. Без JavaScript кнопка генерації неактивна, показано інструкцію для ручного відгуку.

Відгуки використовуються для читабельності, навігації й зручності. Вони не є підставою автоматично змінювати наукові висновки чи рівні впевненості.

## QA

- `node --test --test-concurrency=1 tests/*.test.mjs` — 15/15 наборів пройдено.
- Усі десять наукових HTML-піддерев збігаються з незалежними digest попередньої версії. Claims, результати, confidence та дати перегляду не змінено.
- Перевірено фактичну генерацію п’яти карток з даних каталогу, їхні links та readiness labels.
- Працюють порожня форма, генерація, зміна відповідей, копіювання, відмова Clipboard API та ручний fallback.
- Відсутність мережевого відправлення, localStorage, beacon та нових tracker APIs перевірено в коді відгуку.
- Новий якір доказів креатину: `#evidence-card`, перевірено його існування. Посібник `#evidence-guide-title` створюється наявним контролером навігації.
- Унікальність HTML IDs, синтаксис JS і `git diff --check` — пройдено.
- Візуальне браузерне QA 360/390 px та фізичний touch-тест залишаються неперевіреними: необхідна browser QA capability недоступна. Адаптивні CSS і DOM adapters не замінюють візуальної перевірки.

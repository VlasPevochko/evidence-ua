# Evidence UA — v59: користування перед першим трафіком

11 жовтня 2026. Попередня версія: v58, commit `b48b9d0f5858673f8c6f9985c1984c198847031d`.

## Що дороблено

- Спільний пошук серед **44 прямих переходів до наявних матеріалів і структур**, а не 44 нових сторінок. Досьє, інтерактиви, два наявні розбори; без запланованих неіснуючих Labs. Саркомер, ядро та інші структури відкривають потрібний стан чинної моделі.
- «Знайти матеріал» у модулях і досьє; на головній — нижче першого екрана, у блоці старту. Герой головної, дизайн, routing та наукові блоки не перероблені.
- Пошук із короткою стартовою добіркою, повідомленням про відсутність результатів, закриттям і поверненням фокуса. На вузькому екрані — повновисотний dialog і одна колонка за CSS.
- Каталог тепер показує прямі збіги, а не лише картку напряму. Порожній запит залишає перелік матеріалів згорнутим; пошук розгортає його.
- Режим заняття у Cell Lab і Nutrition Lab: приховує зовнішній header, залишає поруч вихід і пошук. Вихід кнопкою або Escape; відкритий dialog має пріоритет. Це локальний режим читання, не завершений Teacher Mode і не API повного екрана.
- Чинний режим заняття Muscle Lab збережено; додано вихід Escape, коли немає відкритого dialog.
- Копіювання посилання зі станом моделі. При недоступному/відхиленому clipboard — поле для ручного копіювання. UTM, token, невідомі параметри й приватні фрагменти не включаються.
- Cell Lab зберігає органелу, рівень пояснення та вкладку; відновлює їх під час переходів історією.
- Nutrition Lab зберігає нутрієнт, крок, деталізацію, масштаб і обрану структуру. Валідовані параметри, коректний fallback, відновлення через popstate. Відтворення зупиняється на pagehide.
- Перехід до ручного відгуку передає лише відомий ID матеріалу. Зібраний текст включає його назву, щоб було зрозуміло, про що відгук. Головна не позначається помилково як креатин.

## Наука, приватність і обмеження

Claims, Sources, Evidence Records, наукові формулювання та рівні впевненості не змінено. Реєстри креатину, дев’яти досьє, Nutrition/Cell/Muscle Lab, художня ілюстрація м’яза й SVG-сцени звірені побайтно з v58. Десять наукових піддерев головної проходять незалежну перевірку попередніх SHA256.

Немає автоматичного надсилання відгуків, аналітики, мережевого транспорту, cookie, fingerprinting або запису пошукового тексту в сховище. Пошук локальний; кількість переходів не є оцінкою доказовості чи числом завершених модулів. Час відтворення залишається темпом інтерфейсу, не виміряною фізіологією.

### Коротка перевірка після публікації

1. Головна → «Дослідити» → «Знайти матеріал» → «Протеїн».
2. Пошук «саркомер» / «ядро»: відкривається відповідна структура, а не чорний екран.
3. Харчування: білки → крок 3 → деталізація → скопіювати посилання → відкрити заново.
4. Cell Lab: органела → вкладка «Джерела» → рівень → скопіювати/відкрити посилання.
5. Режим заняття → пошук → закриття → вихід; джерела та докази доступні.
6. «Поділитися враженням» з досьє → зібрати текст: у ньому правильна назва матеріалу. Текст передається вручну.

# Evidence UA Video Factory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an isolated reusable Remotion video factory inside Evidence UA and deliver the first `CreatineJourney` 9:16 composition without changing the existing site build or published `dist/` snapshot.

**Architecture:** Add a standalone `video/remotion/` Node/TypeScript project with its own exact-pinned Remotion dependencies. Keep scientific claims, source metadata, composition metadata and scene timing in data modules; reusable Remotion components consume those values as props. The first composition is a seven-scene, 59-second Ukrainian short using authored diagrams/motion graphics only, so later generated footage can replace backgrounds without changing the data contract.

**Tech Stack:** Node 24, TypeScript 5.9.3, React 19.2.3, React DOM 19.2.3, Remotion 4.0.534, `@remotion/cli` 4.0.534, ESLint 9.19.0, Vitest 5.0.4.

**Spec:** `docs/superpowers/specs/2026-10-14-evidence-ua-video-factory-design.md`

## Global Constraints

- Do not modify repository-root `src/` or `dist/` for video work.
- Do not add a repository-root `package.json`; all Node dependencies live under `video/remotion/`.
- Use exact Remotion package versions; all `remotion` and `@remotion/*` packages must be `4.0.534` with no caret.
- `CreatineJourney`: 1080×1920, 30 fps, 59 seconds, Ukrainian.
- Preview-first: do not render/export an MP4 unless explicitly requested.
- Drive animation with Remotion frame APIs (`useCurrentFrame()`, `useVideoConfig()`, `interpolate()`/spring/easing), not CSS transition/animation.
- Numerical claims live in data files and require valid source IDs; visual components must not hard-code Evidence UA scientific numbers.
- Current Evidence UA video tokens are `background #0d0f12`, `accent #e7bd46`, `text #f4f2ed`, `muted #aeb2ba`, with `Inter, Arial, sans-serif` as the site font stack.
- Follow `.agents/skills/evidence-ua-video/` evidence and video-contract rules throughout.

## Review Focus

1. **Unknown source ID:** validation must reject any claim or scene whose `sourceIds` reference a missing source.
2. **Unsourced numeric claim:** validation must reject a numeric display claim with an empty source list.
3. **Timing drift:** seven scene durations must total exactly 59 seconds / 1770 frames at 30 fps.
4. **False precision:** gradual muscle accumulation must remain qualitative; no fabricated day-by-day percentage curve may enter scene data.
5. **Repository isolation:** final branch diff must contain no implementation changes under root `src/` or `dist/`.

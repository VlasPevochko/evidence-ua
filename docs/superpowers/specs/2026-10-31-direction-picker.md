# Вибір напрямів після натискання

Доручення власника: шість нумерованих напрямів під анімованою лінзою приховані; «Обрати напрям» відкриває оформлену панель із шістьма посиланнями. Прокручування відкриває лише зображення й кнопку.

Рішення реалізації: окремий native dialog біля лінзи, дві колонки на ПК і одна на телефоні; на коротких екранах прокручується панель. Використати шість наявних власних ілюстрацій. Зберегти канонічні назви, статуси та адреси, включно з переходом до бібліотеки добавок. Закриття: хрестик, Escape, фон; повернення фокуса до кнопки. Зміна маршруту та pagehide закривають панель. Старі #cards відкривають її. Без JavaScript або dialog API кнопка веде до directions.html. Вміст сторінок і наука не змінюються.

Доручення достатньо конкретне для виконання; деталі оформлення обрано виконавцем. Публікація цього GitHub-проєкту йде через PR; нове злиття потребує рішення власника згідно з CLAUDE.md.

# Лінза: видимі дії та м’яке ядро

Всеслав погодив реалізацію рекомендацій аудиту PR #133 повідомленням «Можеш зробити?».
База: GitHub main, dad0b3efc742aebbc74cfc3635017dee8503ad5c.

## Результат

- Прозорі картки напрямів не приймають мишу або дотик; Tab відкриває всі шість реальних посилань.
- Розкриття визначається геометрією самої лінзи. На 844×390 та 390×667 центральна кнопка має проявлятися, поки її видно.
- Ядро трохи піднімається й збільшується під той самий native scroll. Краї половин пом’якшуються тільки під час розкриття; закрите зображення зберігає цілісність.
- Кількість напрямів лишається в ядрі. Сусідні підписи не повторюють її; підказка прокрутки зникає після першого відкриття без стрибка макета. Допоміжний мобільний текст стає читабельнішим.

## Підхід

Зберігаємо HTML/CSS/ES modules, два WebP, один native #cards anchor і шість канонічних посилань. Контролер читає rect stage, а не всього каталогу; для старої розмітки без stage є fallback до секції. CSS керує рухом та масками; стан прозорих карток задає контролер за тим самим порядком появи.

Альтернатива зі статично відкритою лінзою прибрала б погоджений зворотний рух. Sticky scroll-сцена додала б перехоплення прокрутки та довжину сторінки. Погоджена рекомендація розвиває поточну сцену.

## Межі

Не змінюємо hero, маршрути, досьє, наукові дані, глобальні теми або інші модулі. No-JS, reduced motion, помилка setup і dispose залишають відкриті дії. Без idle RAF-loop і нових залежностей. Прокрутка не перехоплюється.

Зміни передаються окремим PR. Злиття й публікація з main належать власнику за CLAUDE.md.

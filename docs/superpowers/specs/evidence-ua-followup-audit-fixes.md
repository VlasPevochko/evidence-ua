# Виправлення восьми знахідок повторного аудиту

Власник доручив продовжити роботу після звіту про вісім підтверджених проблем. База: `b96c3c6`, PR №123. Потрібні мінімальні виправлення наявних функцій, без перебудови сайту.

1. Форматер результату зберігає тип статистичного інтервалу з `result.intervalType`; звичайні ДІ та відсутні межі зберігають коректне відображення.
2. Порівняння добавок показує стан оцінки окремих тверджень із чинних даних; попередня оцінка не видається за формальний перегляд.
3. На телефоні вибрана структура Nutrition Lab лишається в кадрі. Звичайне відтворення зберігає фокус за кроком.
4. Копіювання посилання зберігає перевірені параметри вправи/бібліотеки та зони Атласу, відкидаючи сторонні параметри.
5. Спільний пошук знаходить Атлас і Вправи та веде на наявні сторінки.
6. Стрілки Muscle Lab і Cell Lab переходять від сфокусованої кнопки, навіть якщо вибрано іншу структуру.
7. Згорнуті методологічні подробиці outcome-записів показують вже внесений контекст і місце витягу, без вигадування відсутніх полів.
8. Відмова читання/запису localStorage не заважає користуватися темою й розміром тексту в поточному сеансі.

Наукові джерела, твердження, рівні впевненості, числові значення, дати й provenance не змінюються. Поточний дизайн і маршрути зберігаються. Авторські файли `dist/` зберігаються; generated outputs відтворюються зі своїх джерел. Усі змінені ресурси отримують узгоджені версії кешу, включно з батьківськими імпортами.

Перевірка: відтворення кожного дефекту до виправлення й проходження після, повний `npm run check`, незалежний перегляд diff та Browser QA в GitHub Actions на телефоні й desktop. Немає локального підтримуваного browser tool; не встановлювати браузер і не запускати саморобний preview. GitHub Pages — чинний production, Sites — історична копія. Зміни оформлюються через PR; гілки не видаляються.
